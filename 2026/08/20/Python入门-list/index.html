内置函数 作用（比较依据） 使用场景
len 按长度比较 找最长/最短的字符串、列表
abs 按绝对值比较 找最接近 0 的数，或离某个值最近的点
int / float 按数值大小比较（类型转换） 列表里是字符串数字，如 ["1", "100"] 的情况
str.lower / str.upper 忽略大小写比较字母顺序 排序人名或单词
