1.3 布尔类型

只有两个值，True 和 False，首字母大写。
可以用 0 和 1 来表示并存放布尔值，Python 的 bool 类型实际上是 int 类型的子类。从数值上看，True 就是 1，False 就是 0。可以直接作为0和1参与运算。
虽然 0 和 1 可以代替布尔值，但在编程中强烈建议直接使用 True 和 False，因为这样可读性更高，同时类型检查更准确，有些函数或库会检查 isinstance(x, bool)。

1.4 空值

None 表示“没有值”或“空值”，是一个特殊类型。

5. 类型转换

函数 作用 示例
int() 转为整数 int(“25”) → 25
float() 转为浮点数 float(“3.14”) → 3.14
str() 转为字符串 str(100) → “100”

注意：
1、int() 函数在将字符串转换为整数时，要求字符串的内容必须直接表示一个整数，不能包含小数点。如果存在小数点，可以先转变为float类型再转变为int
2、不能用 int()或 float() 直接转换复数，会报 TypeError。但可以分别取实部和虚部再转换。不过复数可以通过str()进行转换，结果是字符串形式如 '(a+bj)'。

7.可变与不可变类型

不可变类型：int、float、str、bool、tuple。值一旦创建就不能修改，修改实际上是创建了新对象。
可变类型：list、dict、set 。值可以原地修改。

8.思考和疑惑

在 C++ 里，char 和 int 是基本类型，直接对应机器层面的字节或整数,而 string,vector 是标准库提供的类，封装了字符数组和操作可以存放char类型的元素。但在 Python 中并非如此.

C++ 的类型体系：

基本类型：int、char、float、double、bool 等，它们由语言直接定义，占用固定内存，运算直接映射到 CPU 指令。
标准库类型/类：std::string、std::vector、std::map 等，它们是类，内部封装了数据（如字符数组）和操作（如 length()、substr()）。使用前需要 #include <string>。
比较特别的：
字符 char：本质是一个 1 字节的整数类型，代表一个 ASCII 字符。比如'A' 就是整数 65。
字符串 string：是 char 的动态数组，本质是一个类，包含指针、长度等成员。

Python 中一切皆对象：

在 Python 中，所有值都是对象。没有 C++那种纯粹的，固定大小的基本类型（类似char,int等）。
比如：
C++ 的 int：它是一个关键字，对应一段固定的内存布局（通常是 4 字节）。编译器看到int 时，直接分配内存，没有任何附加信息。
Python 的 int：它是一个对象。当你写下 1 时，Python 不仅在内存中存了数字 1，还存了这个数字的元数据（比如：它是什么类型？它被引用了多少次？）。bool 是 int 的子类，True 是 bool 类的实例。

C++ 的 char：它c++的字符类型，它的基本单位通常是一个字节，直接存储 ASCII 值或编码字节，能表达的东西比较局限，同时你不能写形如 'a'.upper()这样的东西，因为 char 不是类，没有成员函数。但是c++的字符串string就有，因为它是一个数据结构。
Python没有和char一样的东西，但是它有 str，这是一个功能齐全的对象。它携带了大量的方法，可以处理大小写、编码、检测等复杂逻辑。字符串（str）的基本单位是 Unicode 码点。
在 C++ 中，char 是基本类型，表示一个字符。但 Python 没有 char 类型，表示单个字符就是使用一个长度为 1的字符串进行的。
为什么 Python 不设计一个 char 类型呢？是因为 Python 字符串是 Unicode 字符串，一个“字符”可能是多个字节（如中文、emoji）不像c++的长度是固定的，甚至一个码点可能由多个码元组成（如组合字符,组合字符的码点数量是理论上无限的,没有任何固定长度能覆盖所有情况）。所以用长度1的字符串来表示一个字符是最好的方法

在赋值时Python的特点也有体现： 在 Python 中，数字、字符串、列表、函数、类等等都是对象。每个对象在内存中都有自己的位置（可以用 id() 查看），而我们的变量 a 只是存了那个位置的地址（指针），所以可以描述为贴标签。

虽然 Python的所有类型都是类，但我们还是可以根据创建后能不能修改和内部的具体结构进行分类：

分类 类型 特点
不可变标量 int、float、bool、None 值一旦创建就不能改变，表示一个单独的值，不是容器
不可变序列 str、tuple 创建后不能修改里面的元素，内部有多个元素，按顺序排列，支持索引、切片、迭代
可变序列 list、bytearray 同样是序列，但内容可以原地修改
映射 dict 存储的是“键值对”，通过键来查找值，可以增删改键值对
集合 set、frozenset 无序不重复，set 可变，frozenset 不可变

注：str 和 tuple 类似，都是不可变序列，但 str 专门用于文本，元素只能是字符（Unicode 码点）。
